# Minhas Tarefas (Angular + Ionic)

Projeto base completo do início ao fim, estruturado com `NgModule` e pronto para rodar com Ionic CLI ou Angular CLI.

## Como rodar na sua máquina

1. Extraia o arquivo ZIP para uma pasta (ex.: `minhas-tarefas-base`).
2. Abra o terminal dentro da pasta extraída.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor:
   ```bash
   ionic serve
   ```
   (ou `npm start`).
